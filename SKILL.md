# Story-First Slide Deck

Build a presentation around a clear audience question, a logical reveal, and one point per slide.

## When to use

A report or idea needs to become a concise presentation.

## Workflow

1. Define the audience, ask, and one-sentence takeaway.
2. Sequence evidence so each slide earns the next.
3. Write action titles before body copy.
4. Add source notes and a spoken transition.

## Output

Return a usable result for the user’s actual task. State assumptions, evidence, and uncertainty where they affect the result. Keep the output format suited to the job: working HTML, a storyboard, a decision brief, a draft, code, or a short answer. Do not claim that a result was tested, published, or verified unless that action was completed.

## Starter prompt

> Plan a [duration]-minute deck for [audience] to help them [decision/action]. Start with the audience’s question and one-sentence takeaway. Create a slide-by-slide outline with action title, one key point, best visual, evidence/source needed, and spoken transition. Use one message per slide. Mark claims that need data. End with a specific ask. Do not decorate uncertain numbers or invent citations.

## Quality check

Before delivery, check that the result answers the stated need, follows the requested format, and makes any important limitation visible. Invite the user to adjust the result when taste or judgment belongs to them.
